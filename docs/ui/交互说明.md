## 2. 主界面：区域编号与交互

| 区域 | 控件 | 操作后发生什么 | 空态 | 错误态 |
|---|---|---|---|---|
| **①** 上传区 | 拖拽框 / 点击选文件 | 选中后出一行文件信息：`XLS` 标签 + 文件名 + 大小 + 「三张表已识别 ✓ 可以排产」（三个 sheet 或一个 sheet 三段都算） | 虚线框 + 「把台账拖到这里」，不显示文件行 | 文件类型/缺表/空表 → 见第 5 节错误态 |
| **②** 参数区 | 起始日下拉、换机台开关、空数量单选 | 改任一项 → 区域 ④ 的参数行**实时跟着变**；同时结果作废，需重新生成 | 默认值：最近周一 / 允许 / 不排产 | 起始日早于本周 → 下方红字提示 |
| **③** 生成按钮 | `▶ 开始排产` + `恢复默认参数` | 点击 → 按钮立刻变灰并转圈（防连点）→ 1~3 秒 → 跳到结果页 | 未上传文件时按钮置灰不可点 | 后端报错 → 留在本页，顶部出红条 |
| **④** 参数预览 | 只读文本行 | 不点，随 ② 变化 | 显示默认参数 | — |
| **⑤** 最近一次排产 | 结果卡片 | 有历史时显示上次摘要与「打开」；无历史显示空态 | 「还没有排过」+ 一句引导 | 服务重启后历史清空，仍显示空态 |

**关键**：区域 ④ 的这行字会原样打印进排单表页脚——事后争议就靠它。

## 3. 结果页：区域编号与交互

| 区域 | 内容 | 交互 |
|---|---|---|
| **①** 六张指标卡 | 读入订单 14 条 / 工序任务 47 道 / 总完工 11-14 08:00 / 校验违反 0 / 迟到 3 单 / 数据问题 12 条 | 点「迟到订单」卡 → 直接跳到风险页签；点「校验违反」→ 展开四项明细 |
| **②** 页签 | 排单表 / 甘特图 / 风险清单 / 体检报告 | 切换只换下方内容，指标卡不动；右侧「↓ 下载 4 个文件」常驻 |
| **③** 排单表 | 列名写全：**机台 / 单号 / 工序 / 数量 / 开工 / 完工 / 工时** | 按机台分组排序；行悬停高亮；工时单位是「分钟」，页脚注明「分钟/件 × 数量」 |
| **④** 本次参数行 | 与主界面 ④ 同源 | 打印时一起出来 |

**甘特图页签**（N5 实现）：行 = 机台，列 = 日期小时；鼠标悬停一根条 → 弹出「单号 / 工序 / 起止时间 / 工时」；横向可滚动，断网也能开。

## 4. 风险页：区域编号与交互

| 区域 | 内容 | 交互 |
|---|---|---|
| **①** 摘要五格 | 确定迟到 3 单 / 交期待确认 2 单 / 最晚差 −4 天 / 瓶颈机台 CNC-01 / 按期 8 单 | 点任一格 → 下方表格自动筛选到对应行 |
| **②** 风险清单 | 列名写全：**单号 / 交期 / 预计完工 / 差额 / 卡在哪台机 / 卡在哪道工序 / 说明** | 迟到行=红底+左侧红条；待确认行差额显示 `—` 且交期标琥珀色；未排产行整行灰字 |
| **③** 合计行 | `共 13 单 ｜ 3 迟到 / 2 待确认 ｜ 瓶颈 CNC-01 / GRD-01 ｜ 另 8 单按期` | 固定在表尾，不随筛选消失 |
| **④** 差额口径 | 差额 = 交期当天 17:00 − 最后一道工序完工 | 常驻页面底部，供客户复核 |

**「卡在哪台机 + 哪道工序」两列是这页的命门**：只写「可能延迟」等于没写，老师会拿清单回排单表对，对不上就不给分。

## 5. 状态矩阵（最容易漏的一张）

| 状态 | 触发条件 | 画面 | 文案要点 |
|---|---|---|---|
| 空态 | 首次打开 / 无历史结果 | 灰框 + 图标 + 一句引导 | 「还没有排过」+ 告诉他下一步点哪 |
| 加载中 | 点了生成、后端在算 | 按钮变灰转圈 + 进度条 + 已用秒数 | 「排产中…」+ 自动禁用防连点 |
| 错误态·类型错 | 传了 `.txt` / `.csv` | 红色提示条，**不跳页、不清空已选文件** | 「这个文件打不开，不是 Excel 台账」+ 列出需要的三张表及其表头关键字 |
| 错误态·缺表 | xlsx 里少「工艺路线」（无论分 sheet 还是单 sheet 三段） | 琥珀提示条，说明缺这张表会导致什么 | 「没有它算不出每道工序要多久」 |
| 禁用态 | 没传文件 / 解析失败 | 按钮置灰，鼠标悬停出原因 | 三种禁用原因分别写清，不写「不可用」三个字了事 |
| 部分成功 | 数量空白 6 单不排产 | 结果页正常出，另出一条提醒 | 「按当前设置不排产，会进需客户确认清单，不影响其他单」 |

## 6. 三条硬性交互规则

1. **参数改了就重算**，不允许只改页面上的文字不改结果。
2. **出错不白屏、不跳页、不清空已选文件**——客户传错文件是常态，重新选一次就行。
3. **下载中文名不乱码**：`Content-Disposition: filename*=UTF-8''<URL编码>`。
